# CellVision AI

Локальный веб-прототип для учебной визуализации морфологии клеток крови. Интерфейс собран на HTML, CSS и JavaScript; локальный Python-сервер выполняет сегментацию OpenCV и хранит аккаунты и историю в SQLite.

## Запуск

1. Установите зависимости из `requirements.txt` в Python 3.10+.
2. Запустите `python main.py`.
3. Откроется `http://127.0.0.1:8765`. Для остановки сервера нажмите Ctrl+C в терминале.

Приложение слушает только loopback-интерфейс и предназначено для локального прототипирования. Не выставляйте его в публичную сеть.

## Возможности

- Регистрация, вход, локальная карточка и история анализов.
- Загрузка изображений, сложные синтетические примеры и наглядное сравнение очистки шума.
- Фото бланка CBC: OCR извлекает Hb и эритроцитарные индексы; пользователь сверяет распознанные поля, после чего запускает лабораторный скрининг без загрузки микрофотографии.
- Watershed-сегментация и измерения площади, диаметра, круглости, эксцентриситета и разброса клеток.
- CSV с данными по каждому сегментированному объекту; отчёт можно распечатать в PDF.
- Эвристическая проверка резкости/яркости и перевод px в µm по пользовательской калибровке масштабной линейки.
- Экспертная разметка отдельных ROI и экспериментальное обучение HOG + линейный SVM по ZIP с train/test; отчёт включает confusion matrix и метрики классов.
- CBC-раздел сравнивает введённый Hb с выбранным порогом и показывает ориентировочные паттерны индексов. Экспериментальная вероятность CBC не показывается в приложении до независимой проверки.
- Экспериментальная классификация дискоцитов, эхиноцитов и стоматоцитов на обученной модели RedTell; результаты ограничены исследовательскими данными.
- Ручная обводка маски на кадре с попиксельными Dice/IoU для сравнения с Watershed.
- Визуальное сравнение двух снимков и учебный атлас клеточных форм.
- Справочник гематологических учреждений Бишкека с ссылками на карты и отзывы.

## Медицинские и приватные ограничения

Изображение мазка не содержит измеренного гемоглобина, а сегментация и классификация клеток не определяют вероятность анемии. Скрипт CBC-модели и веса Kaggle сохранены для исследовательской работы, но сайт больше не выводит полученную от них вероятность. При вводе Hb сайт сравнивает лабораторное значение с выбранным порогом; дополнительные индексы отображаются как ориентировочные паттерны. Kaggle-набор не сообщает клиническую верификацию меток и возраст участников. Модель не валидирована в Кыргызстане и не предназначена для клинических решений. CV на изображении не является лабораторным RDW.

### Фото лабораторного бланка

Для OCR приложение использует внешний сервис [OCR.space](https://ocr.space/ocrapi), движок 3, язык русский и распознавание таблиц. Создайте API-ключ на [странице OCR API](https://ocr.space/ocrapi/freekey) и укажите его в `.env` в корне проекта как `OCR_SPACE_API_KEY=ВАШ_КЛЮЧ`. Файл `.env` исключён из Git и загружается при старте. Зависимость от Tesseract и его локальная установка не требуются. Бесплатный тариф сейчас ограничивает файл 1 МБ; приложение сжимает изображение и сообщит, если размер всё равно превышает лимит.

Фото отправляется через HTTPS стороннему OCR-провайдеру; не загружайте документ с именем, датой рождения, адресом, штрих-кодом или другими идентификаторами. Перед оценкой вручную сверьте Hb, единицы измерения, пол/возрастную группу и остальные распознанные показатели с оригиналом. OCR может перепутать символы и числа. Основной ответ — сравнение Hb с порогом для выбранной группы; процента клинической вероятности эта проверка не выдаёт. CBC-модель не выдаёт вероятность в интерфейсе. При отсутствии или сомнительном Hb внесите результат вручную либо обратитесь к врачу.

### Учебная лаборатория

Откройте раздел «Учебная лаборатория» в меню. В ней четыре опыта: виртуальная зелёная лампа, Sobel-карта перепадов яркости, фотометрический профиль центрального просветления и сводная PNG-панель. Метрики не калиброваны и не диагностируют анемию; лаборатория не использует реальные образцы.

Синтетические образцы и SVG-атлас являются программными схемами, не фотографиями пациентов. Алгоритм не прошёл клиническую валидацию, сертификацию медицинского изделия или аудит безопасности. Не используйте реальные идентификаторы и медицинские сведения в этом MVP.

### Обучение модели на открытых данных

Скрипт `train_cellvision.py` загружает размеченную часть RedTell с Zenodo, проверяет опубликованную контрольную сумму и обучает классификатор форм отдельных эритроцитов. Запустите из папки проекта:

```powershell
.\.venv\Scripts\python.exe train_cellvision.py
```

Набор содержит несбалансированные классы и не даёт идентификаторов пациентов. Поэтому отчёт использует разделение по исходным микроснимкам; оно снижает утечку одинаковых клеток в train/test, но не доказывает переносимость на новых пациентов, камеры или лаборатории. Скрипт сохраняет веса в `data/models/`, метрики — в `data/models/redtell_training_report.json`. Только если модель проходит заданный порог отложенной balanced accuracy и macro-F1, она подключается к приложению; после обучения перезапустите сервер. Архив и веса исключены из Git.

Источник: Makhro et al., *Red Blood Cell RedTell Dataset*, Zenodo [10.5281/zenodo.7801430](https://doi.org/10.5281/zenodo.7801430), лицензия CC BY 4.0. Применение датасета и производной модели требует атрибуции; подробности и ограничения приведены в [data/README.md](data/README.md).

Вывод модели — только исследовательская оценка видимой морфологии клетки. Он не устанавливает анемию, не оценивает её вероятность и не заменяет общий анализ крови/заключение специалиста. В текущем UI оценивается классификация клеток, но не рассчитываются Dice/IoU для масок сегментации. Малярия, дифференцировка лейкоцитов и оценка тромбоцитов пока не реализованы как автоматические функции. План сбора данных и анализа см. [EXPERIMENT_PROTOCOL.md](EXPERIMENT_PROTOCOL.md).

### Обучение CBC-модели на небольшом Kaggle CSV

В каталоге `data/datasets/anemia_kaggle.csv` должен лежать CSV с колонками `Gender, Hemoglobin, MCH, MCHC, MCV, Result`. Набор содержит 1 421 запись (801 класс 0, 620 класс 1); файл около 34 КБ. Источник: [Kaggle anemia-dataset](https://www.kaggle.com/datasets/biswaranjanrao/anemia-dataset), CSV в [публичном зеркале GitHub](https://github.com/maladeep/anemia-detection-with-machine-learning/blob/main/anemia%20data%20from%20Kaggle.csv).

```powershell
.\.venv\Scripts\python.exe train_kaggle_anemia.py
```

Фиксированное стратифицированное разбиение по строкам: train/validation/test 65/15/20. Внутренняя проверка на тестовой части из 284 строк дала ROC-AUC 0,625, чувствительность 63,7%, специфичность 60,0%, Brier score 0,233. Эти значения приведены как техническая запись эксперимента, а не как характеристика медицинского качества; набор не имеет ID пациентов, документированного способа установления меток или внешней проверки. Поэтому CBC-вероятность выключена в интерфейсе. CSV и веса хранятся в `data/` и исключены из Git. Предыдущий `train_cbc_anemia.py` относится к старой NHANES-версии.

### Исследовательская модель по целому мазку

`train_anemia_image.py` подготовлен для экспериментального обучения на оригинальных изображениях AneRBC-I и требует файлы набора (около 7,4 ГБ). Скрипт делит данные по ID исходного изображения. Даже при наличии обученных весов приложение не показывает вероятность по фото до независимой проверки на пациент-отложенных данных; сегментация и классификатор клеток не подменяют лабораторное измерение Hb.

`cellvision.db` хранит локальные профили, хэши паролей и историю с JPEG-представлениями изображений. Держите файл в защищённой пользовательской папке и не отправляйте его третьим лицам.
