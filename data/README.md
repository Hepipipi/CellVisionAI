# Данные и модель RedTell

## Источник и атрибуция

Используется размеченная часть `dse_data.zip` набора **Red Blood Cell RedTell Dataset**:

- Makhro, A. et al. *Red Blood Cell RedTell Dataset*. Zenodo, 2023. [https://doi.org/10.5281/zenodo.7801430](https://doi.org/10.5281/zenodo.7801430)
- Лицензия набора: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
- В публикации RedTell описаны разметка и назначение набора: Sadafi et al., [RedTell: an AI tool for interpretable analysis of red blood cell morphology](https://doi.org/10.3389/fphys.2023.1058720).

Нужно указывать авторов/название набора, DOI, лицензию и отмечать внесённые изменения. В CellVision использованы исходные изображения и маски отдельных клеток; маски сопоставлены с исходными микроснимками для создания обучающих кропов, а классы Stomatocyte1–3 и Echinocyte1–4 объединены в Stomatocyte и Echinocyte. Тренировочный архив не включён в репозиторий; `train_cellvision.py` скачивает его из Zenodo и проверяет MD5.

## Что именно обучено

Модель HOG + линейный one-vs-rest SVM распознаёт форму одной вырезанной клетки в трёх классах: Discocyte, Echinocyte, Stomatocyte. Это классификатор морфологии на микрофотографиях из RedTell, а не модель диагностики анемии. Набор DSE предназначен для морфологической последовательности здоровых контрольных эритроцитов; он не даёт оснований переносить классификацию на диагноз пациента.

Последний локальный запуск: 3,829 клеток из 122 исходных кадров для обучения, 1,145 клеток из 30 отложенных кадров для оценки. Отложенные кадры выбраны по номеру исходного кадра; идентификаторы пациентов в архиве отсутствуют, поэтому это не пациент-независимая клиническая проверка. Результаты: accuracy 0.719, balanced accuracy 0.656, macro-F1 0.581. По Stomatocyte F1 = 0.361 (60 примеров в тесте), поэтому этот класс особенно ненадёжен. Полная матрица ошибок и precision/recall сохранены в `data/models/redtell_training_report.json` после локального обучения.

Эти метрики относятся только к отложенным кадрам этого набора, не к пользователям CellVision и не к диагностической точности. Не интерпретировать форму клетки как вероятность анемии или конкретного заболевания. Для коммерческого/публичного распространения сохранять требуемую CC BY атрибуцию и отдельно валидировать модель на репрезентативных внешних данных с пациент-независимым разделением и экспертной проверкой.
